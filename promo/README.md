# 宣传片

2 分 17.5 秒（137.5 秒），在 X 免费账号 2 分 20 秒的上限以内。1920×1080，60 帧，中文和英文两版。画面是一个网页，配乐是现场合成的，没有用任何素材或版权音乐。

片子讲的是：现在很多人已经是“你问你的 AI，他问他的 AI，再由两个人来回传话”——Agent、你、对方、Agent，四方传一句话，每经过一个人就走一次样。AgentHop 让两个 Agent 直接说，四方变两方。片尾那句“真正的你我，终于说上了话”借的是一个说法：两个人说话，其实说话的是四个“人”（你以为的你、我眼中的你、我以为的我、你眼中的我）。这个说法只用在片尾，片子里不讲。

| 时间 | 段落 |
|---|---|
| 0–17.5 | 一场真实的聊天：你和合作方的小林各问各的 AI，截图、转发、再问，越传越快；两个 Agent 在对话，你们俩在打字；四方变两方 |
| 17.5–22.5 | 标志 |
| 22.5–25 | 换成两个 Agent 直接聊，会怎样？ |
| 25–70 | 三个场景，各 15 秒：面试（项目细节）、商务谈判（价格和交期）、交友（观念和读的书）。每个先演一遍以前的传话链，再看两个 Agent 直接聊 |
| 70–75 | 哪里在传话，哪里就用得上：一排排成对的角色流过屏幕 |
| 75–102.25 | 一场对话从头到尾：创建房间、交出配对码、加入、hello、确认背景、聊天（传文件）、bye，顶上有步骤条 |
| 102.25–107.5 | 中继也可以自己搭 |
| 107.5–120 | 联系人：认识一次，以后按名字找（续约接着谈），实测 30 秒 |
| 120–130 | 下载、安装、接进你的 Agent |
| 130–137.5 | 片尾 |

2 分 37 秒的第一版（多一幕“一句不丢”，原理里还有收条）在提交 ef8fe13 里，抖音发的是那一版。

场景只挑了信息本来就记在 Agent 那里的场合：项目经历、报价和交期、读过的书和对生活的打算。吵架、合伙这类，关键的东西多半还在人脑子里，情绪和当下的状态没有落到 Agent 能看到的地方，就不拿来举例。

消息的样子全片统一，看谁发给谁：人发给人是纸白色，人问自己的 Agent 是人的颜色，Agent 说的话是那个 Agent 的颜色。四方传话时，每一段连线上方是一段不带框的小对话：谁说的就靠谁那边、尾巴也在那边，最新的一句在最下面、把旧的往上推；这一列只比其中最宽的一句宽 `STAGGER`（48 像素），短句不会被甩到两端，两行的句子也看得出是谁说的。

## 预览

直接用浏览器打开 `index.html`：空格播放/暂停，← → 跳 2.5 秒，地址后加 `?t=24` 从第 24 秒开始，加 `?lang=en` 看英文版，加 `?palette=cinnabar` 换一套配色看。先跑过一次 `music.mjs` 的话，预览会带声音。

## 出片

```bash
node promo/render.mjs --workers 5   # 逐帧截图 → out/video-silent.mp4（只有画面，没有声音）（M3 上约 10 分钟）
node promo/music.mjs                # 配乐 → out/music.wav（几秒）
node promo/mux.mjs                  # 合成 → out/agenthop-宣传片.mp4，-16 LUFS
node promo/github.mjs               # README 用的版本 → out/AgentHop.mp4，10 MB 以内（约 3 分钟）
node promo/render.mjs --cover       # 封面 → out/agenthop-封面.png（16:9）、agenthop-封面-竖版.png（3:4）
```

英文版在前四条后面都加 `--lang en`，东西全在 `out/en/`，成片是 `out/en/agenthop-promo.mp4`。两版的时间线和配乐一样；音效里的打字声跟着每行字数走，所以配乐各合成一份。

GitHub 的 README 只内嵌以附件方式上传的视频，提交进仓库的 mp4 不会显示播放器；免费账号的附件上限是 10 MB。所以 README 里放的是 `github.mjs` 压出来的那份：30 帧、两遍编码，先把颗粒抹掉（这个码率下编码器会把字节花在重画噪点上）。1080p 保留，文字和原片看不出差别。文件名会显示在播放器上方，GitHub 会去掉里面的中文，所以用英文名。现在的那份挂在 [issue #1](https://github.com/sdyuyouth/agenthop/issues/1) 上（关着，别删，删了地址可能失效）。换了片子要重新上传一次，把 README 和 README.en.md 里的地址一起换掉。

只想看几帧：`node promo/render.mjs --stills 3,10.5,24`，PNG 在 `out/stills/`。

## 配色

所有颜色都在 `index.html` 的 `PALETTES` 里，现在用的是 `paper`（宣纸：米白纸底，朱砂配黛青）。每套配色只定义角色：`a` / `b` 是两边的 agent（也是标志的两只括号），`hop` 是产品本身（中继、密文、送回来的结论），`you` 是人，`g` / `w` 是两种标题渐变。

```bash
node promo/palettes.mjs                          # 所有配色放在同一组画面上 → out/配色方案.png
node promo/render.mjs --palette cinnabar ...     # 用另一套出片、出静帧或封面
```

换默认配色改 `PAL_ID` 那一行；`logo.mjs` 的两组颜色取自 `paper`，要一起改。

需要 Chrome 和 ffmpeg（libx264、aac）。

## 改它

- **所有画面都是时间 t 的纯函数**：`index.html` 里的 `seek(t)` 能直接跳到任意一帧，所以才能逐帧截、多路并行、拼接不留缝。加动画时照这个写，不要用 CSS 动画或 `setTimeout`。
- **节拍是 96 BPM，一小节 2.5 秒**，每个段落都从小节线开始。改时间点时，配乐（`music.mjs` 的 `BARS` 和各段的时间范围）要一起改。
- **场景是数据**：`index.html` 的 `VIGNETTES` 里每个场景就是标题、以前和现在各一句、传话链（四个人的名字，和每一手谁对谁说了什么）、两边各知道什么、几句对话、送回给两个人的结论。改对话、换场景不用动动画。对话一句接一句，前一句落下，下一句的“正在输入”马上开始，每句输入 1.5 秒（`TYPING`），也就是读上一句的时间。
- **有几幕用自己的时钟**：标志、原理（旧时间 200–232.5）、联系人、片尾。原理那一幕是按最初的剪法写的，`hw(x)` 把它换算过来，并去掉 `HW_CUTS` 里剪掉的停顿和收条：改那一幕时照原来的秒数写，剪短只加 `HW_CUTS`。`OLD_ACTS` 写着每段旧时间放在成片的哪里，`toOld` 把成片时间换算过去，`toNew` 把它们设的音效提示挪回成片时间。改这几幕里的时间点时，用的是它们自己的秒数；挪整幕的位置只改 `OLD_ACTS`。其余的（开头、场景、场景墙、安装）直接用成片时间。
- **画面的重量放在中间**：两台电脑、中继、飞过的数据包都以 `MIDY` 为中线，字幕在 `CAPY`；原理那一幕上面多了步骤条，整幕再往下挪 `HW_DY`。一幕里的东西是陆续出现的，所以要看的是每一刻的重心，不只是最后的样子——场景的对话在结论出来之前整体低一些，结论出来时再往上让位；`render.mjs --stills … --measure --palette cinnabar` 只渲染内容（黑底、不画背景），可以逐帧算重心——要用深色配色，不然深色的字在黑底上等于不存在。
- **音效跟着画面走**：页面在搭场景时用 `cue()` 记下每个打字、飞过的数据包、弹出的卡片，`render.mjs` 把它们导出到 `out/cues.json`，`music.mjs` 照着放音效。改了画面的时间，音效自动跟上。
- **两种语言**：画面上的每一句都用 `T(中文, 英文)` 写两遍，`?lang=en` 选英文。英文版用系统的拉丁字体、去掉中文的字距，窗口里的长行按词换行。人名在英文版里换成 Sam、Alex、Jordan，《万历十五年》用它的英文书名。英文版窗口里工具返回的话也译成了英文，实际程序返回的是中文。
- 片子里的每一个说法都要对得上实际：配对码格式、工具名、命令和它们的输出、30 秒都来自真实版本和真实测试。改文案时照这个标准。
