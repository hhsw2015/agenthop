# 蜂群核心(一页版;其余文档都是本页的展开,冲突以冻结契约为准)

## 定义(user 终定调 2026-10-04)
**这是一人公司(user 终定调):你=唯一的人,集群=你的公司,节点=你的数字员工。** 一人公司的全部杠杆在于:老板的时间是公司唯一不可再生的资源,所以公司的每一条制度都为「少占用老板」服务——这就是北极星三件事(给目标/看观测/裁三类)的出处,也是为什么「打扰 user」在这里是要计数的成本而不是正常沟通。节点 = Dot 数字员工;集群 = Dot 组织 = 一家真实运作的公司。 一切设计判断的最终参照系:真公司怎么解决这个问题,这里就该有对应机制(工单/考勤/验收/审计/招聘/裁撤/预算/章程),且因为员工是数字的,每条机制都该比真公司更干净(知识属于公司不属于个人、裁撤零摩擦、制度由机器执行而非自觉)。

## 单一接口(user 定调 2026-10-04:老板只跟个人助理说话)
**协调者 Dot = 你的个人助理 = 你与公司之间唯一的人格化接口。** 成果层层汇报归集到助理,助理只把三样东西送到你桌上:① 该你裁的(三类,带决策包:一页、可裁、含建议);② 该你验收的(带证据链,不是转述);③ 你主动问的任何事(助理有全局视野,任何问题一站式答复)。反向同样成立:你只对助理说话——你的一句话由助理翻译成工单/契约/裁定,分发到对应员工,你永远不需要知道「这事该找谁」。员工绕过助理直接找你 = 机制缺陷(计入外部激活);你绕过助理直接指挥员工 = 可以但不必(那是你在替助理干活,通常意味着助理失职,同样记一笔)。本节的机制含义:全部升级路径的终点统一收敛到协调者,viz 看板是助理的「桌面」,user 门物料(决策包)是助理的「呈批件」格式。

### 代理权(user 定调:老板睡觉时,助理代行老板)
你离场(睡觉/下班)期间,协调者 Dot **代行老板的日常决策权**,边界三条:
- **可代**:一切可撤的(R3 判据)——排程、派发、范围内裁定、票据内支出、审查轮次推进。判断标准:事后发现代错了,一个动作能纠回来的,都代。
- **不可代**:三类裁决本体(改原则/超票花钱/不可逆)——这些挂 approval-wait 等你醒,挂着不拦别的路;唯一例外是你预授权过的票据(今晚的强制关机授权就是先例:一次性、限本次、用完即废)。
- **代行有账**:代理期每个决策进**晨间追认单**——你醒来第一份呈批件就是「你睡着时我替你拍了这些板:各一行+理由+如何撤销」,你逐行追认或翻案;翻案的执行成本已被「只代可撤的」兜住。
这不是新机制,是既有零件的组合:R3 两层判据(可撤才自主)+预授权票据+决策留痕(control-log)+呈批件格式。今晚实际已这么跑过一夜,本节把它从默契升级为制度。

## 北极星
**目标一句话(user 2026-10-04 定):一个可以自我协作、自我驱动的 AI 军团。**
操作化即「晚上交代,早上验收」。人只做三件事:给目标、看观测、裁三类(改原则/花钱/不可逆)。
检验:数「外部激活」次数——人或协调者人肉推一把才动的每一次 = 一个待补机制。
(自我协作=四柱的可观测+通讯;自我驱动=自驱动柱;军团的成长=递归改进柱。目标与四柱一一对应,不另立体系。)

## 铁律(全部从失败中来,编号=学费单)
1. 状态是证据,不是信念(F13)。完成=验收过,不是自报(F20)。
2. 推进责任任何时刻必须有耐久持有者;只活在内存/消息/记忆里=停摆伏笔(F21)。
3. 交接两端都要监管:有人负责做+有人负责收(F22)。
4. 名册/单信号不定罪;两证据面;suspected≠dead(F16/F17/F18)。
5. 期限只判死活,不判快慢;估算不进机制(估算系统性不准)。
6. 空等是最大成本;并行=时间优化;贵模型一次做对=省。
7. 裁定与契约文字一个动作;文档/口头无强制力,机制才有(F8×3)。
8. 问询带默认,到期按默认;真实门控才裸等(R3-b)。
9. 域不合不领;单编辑者;越界=撤回重来。

## 承认的缺陷与方法论(user 定调:谁都想不周全)
**设计不求周全,求两个速度:缺陷浮出速度(可观测性+对抗审查+实弹演练)与缺陷→机制转化速度(F 四步,分钟级记录、小时级机制)。** 系统必然有未知缺陷;每个缺陷的第一次出现是学费,第二次出现是免疫系统失效(最高事故)。

4. **协调层鉴别**:消息无签名,靠全员善意(bus-identity v1.5)。
